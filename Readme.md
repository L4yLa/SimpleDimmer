# SimpleDimmer
ゲーム中のライトとウォールの明るさを下げます。

# 設定
プレイ前の設定画面（Gameplay Setup）の「Simple Dimmer」タブ

| 項目 | 内容 |
|---|---|
| Enable | 有効にする |
| Dimming Lights | ライトを暗くする |
| Dimming Walls | ウォールを暗くする |
| Brightness | 明るさ（0〜100%） |
